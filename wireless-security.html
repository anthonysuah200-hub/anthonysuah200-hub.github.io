Wireless Security

Learn how Wi-Fi protects (and fails to protect) data in the air — encryption standards, common attack patterns, and the controls defenders use to lock a wireless network down.

⚠️ Safe Learning Rule
Only test wireless networks and devices you own or have explicit written permission to test. This lesson explains how wireless attacks work so you can recognize and defend against them — it is not a walkthrough for attacking networks you don't control.
📚 Lessons

Wireless Security Lessons

1. Wi-Fi Encryption Standards

DeprecatedWEP (Wired Equivalent Privacy) was the original Wi-Fi encryption standard. Its key scheduling is cryptographically broken and it can be defeated quickly with widely available tools — it should never be used.

LegacyWPA improved on WEP with TKIP but is also considered outdated and weak by modern standards.

CommonWPA2 introduced AES-CCMP encryption and is still the most widely deployed standard. Its main weakness is the 4-way handshake, which can be captured and attacked offline if the passphrase is weak.

CurrentWPA3 replaces the older handshake with SAE (Simultaneous Authentication of Equals), which resists offline password-guessing even against weak passphrases, and adds forward secrecy so past traffic stays protected if a key is later compromised.

2. SSID, BSSID, and Hidden Networks

The SSID is the human-readable network name (e.g. "HomeWiFi"). The BSSID is the MAC address of the specific access point radio broadcasting it. "Hiding" an SSID stops it appearing in a casual scan, but it is still visible to anyone actively monitoring wireless traffic — so it's a minor inconvenience for attackers, not a real security control.

3. Common Wireless Attack Patterns

Rogue access point — an unauthorized AP connected to a network, sometimes set up by an attacker (or an employee) that bypasses normal security controls.

Evil twin — a fake access point broadcasting a legitimate-looking SSID to trick devices into connecting, so traffic can be intercepted.

Deauthentication attack — forged management frames that disconnect a device from an AP, often used to force a device to reconnect so its handshake can be captured.

Handshake capture & offline cracking — capturing a WPA2 4-way handshake and attempting to recover the passphrase offline using a wordlist. A long, random passphrase makes this impractical.

4. Defensive Controls

Use WPA3 where supported, or WPA2-AES at minimum. Choose a long, unique passphrase (16+ characters). Disable WPS (Wi-Fi Protected Setup), which has known PIN-brute-force weaknesses. Segment guest and IoT devices onto a separate network/VLAN. Keep router firmware updated, and monitor for unrecognized access points on the network.

📖 Wireless Dictionary

Key Terms

WPA3 / SAE

The current Wi-Fi security standard; SAE is its handshake method, designed to resist offline password-guessing attacks even against weaker passphrases.

WPS

A setup feature meant to simplify connecting devices to a router. Its PIN implementation is often vulnerable to brute-force and is generally recommended to be disabled.

4-Way Handshake

The exchange an AP and device use to prove both know the network passphrase and derive session keys, without sending the passphrase itself over the air.

Rogue AP

An unauthorized wireless access point connected to a network, which can bypass firewall and monitoring controls if not detected.

Evil Twin

A malicious access point mimicking a legitimate SSID to trick users into connecting so their traffic can be observed or altered.

Deauthentication Frame

A wireless management frame that disconnects a client from an AP; forged deauth frames are used to disrupt connections or force reconnection.
