Injection

Injection vulnerabilities occur when untrusted input is interpreted as part of a command or query instead of being treated strictly as data.

Why does it matter?

If an application builds commands or database queries directly from untrusted input, an attacker may be able to manipulate the application's intended behavior.

🛡️ Defensive principle

Applications should separate data from instructions and validate input according to the application's requirements.

Safe training example

The following intentionally vulnerable example is for a local classroom lab only. 

# INTENTIONALLY VULNERABLE — TRAINING ONLY

username = request.form["username"]

query = "SELECT * FROM users WHERE username = '" + username + "'"

database.execute(query)

How should it be fixed?

# SAFER APPROACH

username = request.form["username"]

query = "SELECT * FROM users WHERE username = ?"

database.execute(query, (username,))

The safer approach uses a parameterized query so the database can distinguish the user's data from the SQL statement.

OWASP TOP 10

Broken Access Control

Access control determines which users are allowed to perform particular actions or access particular resources.

Example

Imagine an application where a normal user can view their own profile. The application should verify authorization before allowing access to another user's private information.

🔐 Security principle

Authentication answers "Who are you?" while authorization determines "What are you allowed to do?"

OWASP TOP 10

Cross-Site Scripting (XSS)

Cross-Site Scripting occurs when an application allows untrusted content to be interpreted as executable content in a user's browser.

Common defenses

  • Validate input according to application requirements.
  • Encode output appropriately for its context.
  • Use secure browser security controls such as Content Security Policy where appropriate.
  • Avoid inserting untrusted content into dangerous HTML contexts.
⚠️ Important

Only test XSS in applications you own or in intentionally vulnerable training environments.
