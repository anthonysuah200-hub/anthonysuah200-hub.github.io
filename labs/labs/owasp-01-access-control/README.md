# SecureBank Lab — Broken Access Control

## Difficulty
Beginner

## Objective

Identify an authorization weakness in the fictional SecureBank training
application.

This laboratory is designed for authorized educational practice.

## Scenario

SecureBank has two types of users:

- Normal users
- Administrators

The application correctly requires users to log in.

However, the application contains a mistake in its authorization logic.

Your task is to identify why a normal user should not be able to access
administrator-only functionality.

## Learning objectives

By completing this lab you should understand:

- Authentication
- Authorization
- Access control
- Privilege boundaries
- Broken Access Control
- Defensive authorization checks

## Flag

The flag is hidden inside the isolated training application.

Do not use this exercise against real websites or accounts.

## Safety

This lab is intentionally vulnerable and should only be run locally
or inside an authorized training environment.
