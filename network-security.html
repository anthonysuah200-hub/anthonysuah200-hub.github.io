LESSON 1

IP Addresses

An IP address identifies a device or network interface on an IP network. It allows devices to know where network traffic should be delivered.

IPv4 Example 

192.168.1.10

Private IPv4 Addresses

Private addresses are commonly used inside local networks and are not directly routable across the public Internet.

  • 10.0.0.0 – 10.255.255.255
  • 172.16.0.0 – 172.31.255.255
  • 192.168.0.0 – 192.168.255.255
🛡️ Security Tip

An IP address by itself does not tell you everything about a device. Network security requires understanding the device, services, permissions and context.

LESSON 2

🔌 Ports & Services

A port is a logical communication endpoint. Applications can use different ports to communicate over a network.

Common Examples

Port Common Service
22 SSH
53 DNS
80 HTTP
443 HTTPS
⚠️ Remember

An open port does not automatically mean a system has been compromised. It means a service is listening for network communication.

LESSON 3

📡 TCP vs UDP

TCP and UDP are transport-layer protocols used to move data between applications.

TCP

  • Connection-oriented
  • Designed for reliable delivery
  • Uses acknowledgements and sequencing

UDP

  • Connectionless
  • Lower overhead
  • Does not provide TCP-style delivery guarantees
💡 Simple Way to Remember

TCP focuses on reliable communication. UDP focuses on lightweight communication without TCP's connection and delivery mechanisms.

LESSON 4

🧭 DNS

The Domain Name System, or DNS, translates domain names into information such as IP addresses so that clients can locate services on networks.

Example

example.com
      ↓
   DNS lookup
      ↓
IP address

Why DNS Security Matters

  • DNS is an important part of normal Internet communication.
  • Incorrect DNS information can redirect users to unwanted destinations.
  • Security teams monitor DNS activity for suspicious behavior.

LESSON 5

🔥 Firewalls

A firewall helps control network traffic according to configured rules. Firewalls can exist on individual devices, servers or network infrastructure.

Firewall Rules Can Consider

  • Source and destination
  • Protocol
  • Port
  • Direction of traffic
  • Application or service
🛡️ Security Principle

A firewall should allow necessary communication while restricting traffic that is not authorized or required.

LESSON 6

🔎 Network Discovery with Nmap

Nmap is a network discovery and security auditing tool. Security professionals can use it to identify hosts, services and other network information in authorized environments.

⚠️ Authorization Required

Only scan devices and networks that you own or have explicit permission to test. For practice, use your own computer, your own virtual machines or an intentionally provided training environment.

Safe Local Example

If you are running a training service on your own computer, you can practice against the local host: 

nmap 127.0.0.1

To learn more about the command and its options: 

nmap --help

What Nmap Can Help Identify

  • Available hosts
  • Open ports
  • Detected services
  • Service versions in authorized assessments
