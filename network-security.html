Network Security

Learn how computer networks communicate, how network devices work, how protocols transfer information, and how cybersecurity professionals protect networks from threats.

Course Progress: 0%

⚠️ Safe Learning Rule

Practice networking and security techniques only on systems, devices, networks, and applications that you own or have explicit permission to test.

The Nmap examples on this page are intended for localhost, your own laboratory, or authorized training environments.

📚 Network Security Lessons

Lesson 1: IP Addresses

An IP address identifies a device or network interface on an IP network. IPv4 addresses are commonly written in dotted-decimal form, such as 192.168.1.10. IPv6 uses a much larger address space and is written using hexadecimal notation.

Understanding IP addresses is important for cybersecurity because security professionals use them when analyzing network connections, investigating logs, identifying systems, and understanding how traffic moves between devices.

Lesson 2: Ports and Services

A port is a logical communication endpoint used by network applications. Different services commonly use different port numbers. For example, HTTPS commonly uses port 443.

Security professionals examine ports to understand which services are available on a system. Unnecessary services should generally be disabled or properly secured because every exposed service can contribute to a system's attack surface.

Lesson 3: TCP and UDP

TCP and UDP are transport-layer protocols. TCP provides connection-oriented communication and includes mechanisms for reliable delivery, while UDP provides a simpler connectionless method of sending data.

Different applications use different transport protocols depending on their requirements. Understanding TCP and UDP helps cybersecurity students interpret network traffic and understand how services communicate.

Lesson 4: DNS

DNS stands for Domain Name System. It translates human-readable domain names such as example.com into IP addresses that computers can use.

DNS is important to cybersecurity because attackers and defenders both interact with DNS infrastructure. Security teams may monitor DNS activity for unusual domains, suspicious requests, or signs of malicious activity.

Lesson 5: Firewalls

A firewall controls network traffic according to security rules. It can allow approved connections and block or restrict traffic that violates the organization's security policy.

Firewalls are an important layer of defense, but they are not a complete cybersecurity solution. Organizations also need secure configurations, authentication, patching, monitoring, encryption, and other controls.

Lesson 6: Network Discovery with Nmap

Nmap is a network exploration and security auditing tool. It can help authorized users discover hosts, identify open ports, and learn about services running in a controlled environment.

Beginners should practice Nmap on their own computer, a private lab, or an intentionally vulnerable training environment. For example:

Safe localhost scan: 
nmap 127.0.0.1
Nmap help: 
nmap --help

📖 Network Security Dictionary

Below are important networking and cybersecurity terms. Each definition explains the concept, how it relates to networks, and why it matters to cybersecurity.

🌐 Networking Fundamentals

Definition 01 Networking

1. Network

A network is a group of computers, phones, servers, and other devices connected so they can communicate and share information or resources. Networks can be very small, such as two computers connected together, or very large, such as the Internet.

In cybersecurity, understanding networks is fundamental because security threats often travel through network connections. Security professionals need to understand how devices communicate so they can identify unusual traffic, protect systems, and investigate incidents.

Definition 02 Networking

2. IP Address

An IP address is a numerical address used to identify a device or network interface on an IP network. IPv4 addresses look like 192.168.1.10, while IPv6 addresses use a much larger address space.

IP addresses are important in cybersecurity because logs, firewalls, monitoring systems, and network tools often use them to identify communication endpoints. A security analyst may examine IP addresses when investigating suspicious network activity.

Definition 03 Networking

3. IPv4

IPv4 is the fourth version of the Internet Protocol. It uses 32-bit addresses and is commonly written as four decimal numbers separated by periods, such as 10.0.0.5.

IPv4 remains widely used in networks around the world. Cybersecurity students should understand IPv4 because many internal networks, security tools, firewall rules, and network logs still use IPv4 addresses.

Definition 04 Networking

4. IPv6

IPv6 is a newer version of the Internet Protocol designed to provide a much larger number of addresses than IPv4. IPv6 addresses use 128 bits and are normally written using hexadecimal characters.

IPv6 is increasingly important as networks grow and more devices connect to the Internet. Security professionals need to understand IPv6 because security policies and monitoring must account for both IPv4 and IPv6 traffic.

Definition 05 Networking

5. MAC Address

A MAC address is a link-layer identifier associated with a network interface. It is normally represented as a sequence of hexadecimal values, such as 00:1A:2B:3C:4D:5E.

MAC addresses are used for communication within local network segments. Security professionals may use MAC addresses when investigating local network devices, analyzing network access, or troubleshooting connectivity.

Definition 06 Networking

6. LAN

LAN stands for Local Area Network. It describes a network covering a relatively small area, such as a home, classroom, office, computer laboratory, or school building.

LANs are important in cybersecurity because many organizations keep internal computers and services within local networks. Security teams protect LANs using firewalls, access controls, segmentation, monitoring, and secure configurations.

Definition 07 Networking

7. WAN

WAN means Wide Area Network. A WAN connects networks across larger geographical areas, such as different cities, countries, or regions.

The Internet can be viewed as a very large interconnected network of networks. WAN security is important because communication may cross multiple locations and network providers, requiring controls such as encryption, authentication, and secure routing.

Definition 08 Networking

8. WLAN

WLAN stands for Wireless Local Area Network. It is a local network that allows devices to communicate using wireless technologies such as Wi-Fi instead of requiring physical Ethernet cables for every connection.

Wireless networks require strong security because radio communication can extend beyond the physical walls of a building. Encryption, strong passwords, secure authentication, and appropriate wireless configuration are important parts of WLAN security.

Definition 09 Networking

9. Subnet

A subnet is a smaller logical network created from a larger IP network. Subnetting allows administrators to divide networks into organized sections.

Subnetting can improve network organization, address management, and security. For example, an organization may place employees, servers, and guest devices into separate network segments to reduce unnecessary communication between them.

Definition 10 Networking

10. Subnet Mask

A subnet mask helps determine which portion of an IPv4 address represents the network and which portion represents the host. A common example is 255.255.255.0.

Understanding subnet masks is important for network configuration, troubleshooting, and security. Incorrect subnetting can cause communication problems or unintentionally expose systems to other network segments.

Definition 11 Networking

11. Default Gateway

A default gateway is the device a computer normally sends traffic to when the destination is outside its local network. In many home networks, the router acts as the default gateway.

From a security perspective, the gateway is an important control point. Network administrators can use routers and firewalls at gateways to control traffic between internal networks and external networks.

Definition 12 Network Devices

12. Router

A router is a network device that forwards packets between different networks. It examines destination information and determines where network traffic should be sent.

Routers are important security devices because they can enforce routing rules, separate networks, and sometimes provide firewall functionality. Proper router configuration is an important part of network security.

Definition 13 Network Devices

13. Switch

A network switch connects devices within a local network and forwards Ethernet frames to appropriate ports. Unlike a traditional hub, a switch can make forwarding decisions based on MAC addresses.

Managed switches can provide useful security features such as VLANs, port security, and network monitoring. These features can help organizations separate devices and control how systems communicate.

Definition 14 Network Devices

14. DHCP

DHCP stands for Dynamic Host Configuration Protocol. It automatically provides network configuration information such as IP addresses, subnet masks, gateways, and DNS servers to clients.

DHCP makes network administration easier, but it must be properly secured. Security teams may monitor DHCP activity because unexpected DHCP servers or unusual assignments can indicate configuration problems or malicious activity.

Definition 15 Networking

15. NAT

NAT means Network Address Translation. It allows devices using private IP addresses to communicate through a device that translates addresses between private and public networks.

NAT is commonly found in home and business routers. Although NAT can reduce direct exposure of internal addresses, it should not be treated as a replacement for a properly configured firewall or other security controls.

🔌 Ports & Protocols

Definition 16 Ports

16. Port

A port is a logical communication endpoint used by network applications. Port numbers help the operating system determine which application or service should receive incoming network traffic.

Ports are important in cybersecurity because open ports may indicate services that are available for communication. Security professionals should understand which services are intentionally exposed and whether those services are properly secured.

Definition 17 Networking

17. Protocol

A protocol is a set of rules that defines how devices communicate. Protocols specify how information is formatted, transmitted, received, and interpreted.

Examples include TCP, UDP, HTTP, HTTPS, DNS, and SSH. Cybersecurity professionals need to understand protocols because network security involves monitoring and protecting the communication processes used by applications and devices.

Definition 18 Transport

18. TCP

TCP stands for Transmission Control Protocol. It is connection-oriented and provides mechanisms for reliable and ordered delivery of data between communicating applications.

TCP is widely used by services such as HTTPS and SSH. Security professionals often analyze TCP connections when investigating network behavior, troubleshooting services, or monitoring suspicious traffic.

Definition 19 Transport

19. UDP

UDP stands for User Datagram Protocol. Unlike TCP, UDP does not establish a traditional connection before sending data and does not provide the same built-in reliability mechanisms.

UDP can be useful where speed and low overhead are more important than guaranteed delivery. DNS, streaming, and some real-time applications may use UDP. Security analysts should understand UDP when examining network traffic.

Definition 20 Web

20. HTTP

HTTP stands for Hypertext Transfer Protocol. It is a protocol used for communication between web clients and web servers. Web browsers commonly use HTTP to request and receive web resources.

Standard HTTP does not provide encryption for the communication. For sensitive information, modern websites generally use HTTPS, which protects HTTP traffic using TLS.

Definition 21 Web Security

21. HTTPS

HTTPS is HTTP protected by TLS. It helps provide confidentiality and integrity for communication between a client and a server.

HTTPS is important because it helps prevent network observers from simply reading or modifying protected web traffic. However, HTTPS does not automatically make a website secure against every application vulnerability.

Definition 22 Remote Access

22. SSH

SSH stands for Secure Shell. It is a protocol commonly used to securely access and manage remote computers through an encrypted connection.

SSH is widely used by system administrators and cybersecurity professionals. Strong authentication, secure key management, and appropriate access restrictions are important for protecting SSH services.

Definition 23 Encryption

23. TLS

TLS stands for Transport Layer Security. It is a cryptographic protocol designed to protect communication between systems by providing encryption, integrity protection, and authentication mechanisms.

TLS is used by HTTPS and many other secure services. Security professionals need to understand TLS because weak configurations, outdated versions, and certificate problems can create security and trust issues.

Definition 24 Networking

24. Packet

A packet is a unit of data transmitted across a network. Network protocols add information to packets so devices can determine where the data came from, where it should go, and how it should be processed.

Security professionals can analyze packets to understand network behavior. Packet analysis can help identify unusual communication, troubleshoot problems, and investigate potential security incidents.

Definition 25 Performance

25. Bandwidth

Bandwidth describes the maximum amount of data that a network connection can theoretically transfer over a given period. It is commonly measured in bits per second, such as Mbps or Gbps.

Bandwidth is different from actual performance. A network can have high bandwidth but still experience delays because of congestion, latency, packet loss, or other problems. Security monitoring may also examine unusual increases in network traffic.

Definition 26 Performance

26. Latency

Latency is the time it takes for data to travel between two points in a network. It is often experienced as delay, especially during interactive activities such as video calls or online gaming.

High latency can result from distance, congestion, routing, processing, or other network conditions. Understanding latency helps cybersecurity students distinguish performance problems from possible security or network configuration issues.

🛡️ Network Security

Definition 27 Security

27. Firewall

A firewall is a security control that monitors and controls network traffic according to defined rules. It can operate on a computer, server, router, or dedicated security appliance.

Firewalls can reduce unwanted network access by restricting traffic that does not meet security requirements. They are an important layer of defense, but they should be combined with other security controls.

Definition 28 Security Monitoring

28. IDS

IDS stands for Intrusion Detection System. It monitors network or system activity and looks for patterns that may indicate suspicious or malicious behavior.

An IDS generally focuses on detecting and alerting rather than directly blocking traffic. Security teams can investigate IDS alerts alongside logs and other evidence to determine whether an event requires action.

Definition 29 Security Monitoring

29. IPS

IPS stands for Intrusion Prevention System. It monitors traffic for suspicious activity and can take configured actions to block or prevent certain traffic.

An IPS can provide an additional layer of automated protection. However, security teams must carefully configure and monitor IPS rules to reduce false positives and avoid blocking legitimate communication.

Definition 30 Privacy

30. VPN

A VPN, or Virtual Private Network, creates a protected communication tunnel between a device and another network endpoint. VPNs are commonly used to protect traffic across untrusted networks and to provide remote access to organizational resources.

A VPN can improve the security of a connection, but it does not make the user anonymous or protect against every cybersecurity threat. Strong authentication and proper VPN configuration remain important.

Definition 31 Network Security

31. Network Segmentation

Network segmentation divides a network into separate logical or physical sections. Different sections can have different security rules and access requirements.

Segmentation can limit how far an attacker can move if one system is compromised. For example, an organization may separate guest Wi-Fi, employee computers, and sensitive servers into different network segments.

Definition 32 Security Model

32. Zero Trust

Zero Trust is a security approach based on the idea that access should not automatically be trusted simply because a user or device is inside a particular network.

Zero Trust emphasizes verification, least privilege, device and user context, continuous monitoring, and appropriate access controls. The goal is to reduce unnecessary trust and limit the impact of compromised accounts or devices.

Definition 33 Cryptography

33. Encryption

Encryption converts readable information into a protected form using a cryptographic algorithm and key. The purpose is to prevent unauthorized people from understanding the protected information.

Encryption is widely used in network security, including HTTPS, VPNs, wireless security, and secure messaging. Good encryption depends not only on the algorithm but also on proper key management and implementation.

Definition 34 Cryptography

34. Hashing

Hashing transforms data into a fixed-length value called a hash. A cryptographic hash function is designed so that changing the input produces a different hash.

Hashing is commonly used for integrity checking and secure password storage when combined with appropriate password-hashing algorithms. Hashing is not the same as encryption because hashes are designed to be one-way rather than normally decrypted back into the original data.

Definition 35 Identity

35. Authentication

Authentication is the process of verifying who a user, device, or service claims to be. Passwords, security keys, certificates, and biometric methods can all be used as authentication factors.

Strong authentication is important because stolen credentials can give attackers unauthorized access. Multi-factor authentication adds another layer by requiring more than one type of authentication factor.

Definition 36 Access Control

36. Authorization

Authorization determines what an authenticated user or system is allowed to access or perform. Authentication answers "Who are you?" while authorization answers "What are you allowed to do?"

Poor authorization can allow users to access information or functions they should not have. Strong authorization checks are therefore an important part of application and network security.

Definition 37 Access Control

37. Least Privilege

Least privilege means giving a user, application, or system only the permissions required to perform its legitimate tasks.

This reduces unnecessary access and can limit the damage caused by compromised accounts or applications. Least privilege is a major principle in secure system and network administration.

🚨 Cybersecurity Concepts

Definition 38 Security

38. CIA Triad

The CIA Triad is a basic cybersecurity model consisting of Confidentiality, Integrity, and Availability. Confidentiality protects information from unauthorized access, integrity protects information from unauthorized modification, and availability helps ensure systems and information remain accessible when needed.

Security professionals use the CIA Triad when thinking about security requirements and incidents. A security control may protect one or more of these principles depending on its purpose and design.

Definition 39 Security

39. Threat

A threat is a potential cause of harm to a system, organization, or piece of information. Threats can come from people, software, technical failures, natural events, or other sources.

Security teams identify threats so they can determine which controls are needed. A threat does not automatically mean that an attack will happen; it represents a potential source of harm that should be considered.

Definition 40 Security

40. Vulnerability

A vulnerability is a weakness in software, hardware, configuration, process, or another system component that could be exploited to cause harm.

Vulnerabilities can result from outdated software, insecure configurations, programming mistakes, weak credentials, or design problems. Security teams work to identify and reduce vulnerabilities before they can be exploited.

Definition 41 Security

41. Risk

Risk describes the potential for a threat to take advantage of a vulnerability and cause an unwanted impact. Risk assessment considers both the likelihood and potential consequences of security events.

Organizations use risk management to decide which security issues require attention and which controls should be implemented. Good cybersecurity is not only about finding vulnerabilities but also understanding and managing risk.

Definition 42 Security

42. Attack Surface

An attack surface is the collection of points where an attacker could potentially interact with or attempt to compromise a system, application, network, or organization.

Open ports, exposed services, applications, accounts, APIs, and remote access systems can all contribute to an attack surface. Reducing unnecessary exposure is an important defensive security practice.

Definition 43 Malicious Software

43. Malware

Malware is software designed to perform harmful or unauthorized actions. Examples include ransomware, spyware, worms, trojans, and certain types of malicious scripts.

Malware can steal information, disrupt systems, damage files, or provide unauthorized access. Security controls such as endpoint protection, patching, application controls, backups, and monitoring can help reduce malware-related risk.

Definition 44 Social Engineering

44. Phishing

Phishing is a form of social engineering in which attackers attempt to trick people into revealing information, opening malicious content, transferring money, or performing another unsafe action.

Phishing messages can arrive through email, messaging applications, websites, or other communication channels. Users should verify unexpected requests, inspect links carefully, and use multi-factor authentication where possible.

Definition 45 Availability

45. DDoS

DDoS stands for Distributed Denial-of-Service. It involves many systems or sources generating traffic or requests toward a target in an attempt to make a service unavailable or difficult to access.

Organizations can prepare for DDoS attacks using traffic filtering, rate limiting, scalable infrastructure, monitoring, and specialized protection services. DDoS defense should be designed according to the organization's actual network and application requirements.

Definition 46 Security Operations

46. Security Monitoring

Security monitoring is the continuous observation of systems, networks, applications, and security events to identify suspicious or abnormal activity.

Monitoring can involve logs, network traffic, endpoint events, authentication activity, and security alerts. Effective monitoring helps organizations discover potential incidents and respond to them more quickly.

Definition 47 Security Operations

47. SIEM

SIEM stands for Security Information and Event Management. A SIEM platform collects and analyzes security-related logs and events from multiple systems.

SIEM technology can help security teams identify patterns that may be difficult to see from a single device. Analysts can use correlated events, alerts, and historical information when investigating security incidents.

Definition 48 Incident Response

48. Incident Response

Incident response is the organized process used to identify, investigate, contain, eradicate, and recover from security incidents.

A good incident response capability includes preparation, monitoring, documented procedures, communication, evidence handling, and lessons learned. The goal is to reduce the impact of incidents and improve future security.

🔎 Network Testing & Nmap

Definition 49 Nmap

49. Nmap

Nmap is a network exploration and security auditing tool. It can be used to discover hosts, examine ports, identify services, and gather information about authorized systems.

Nmap is widely used for legitimate network administration and security testing. Beginners should practice only on systems they own or have explicit permission to test. A safe starting point is scanning the local computer using nmap 127.0.0.1.

Definition 50 Network Testing

50. Port Scanning

Port scanning is the process of checking network ports on a system to determine which ports appear accessible. Security professionals can use authorized port scans to understand what network services are exposed.

Port scanning can be useful for defensive security because administrators can compare actual exposure against intended configurations. Scanning systems without permission can violate policies or laws, so authorization is essential.

Definition 51 Network Testing

51. Network Discovery

Network discovery is the process of identifying devices, hosts, services, or network information within an authorized environment. It helps administrators understand what systems exist and how they are connected.

Security teams can use network discovery during asset management and security assessments. Knowing which devices and services are present helps organizations identify unauthorized systems and reduce unknown exposure.

Definition 52 Network Analysis

52. Packet Capture

Packet capture is the process of collecting network traffic for analysis. Tools can capture packets and display information about protocols, addresses, ports, and other network details.

Packet capture is useful for troubleshooting and security investigations. Analysts can examine traffic to understand how systems communicate and identify unusual patterns. Captured traffic may contain sensitive information, so it must be handled securely and only collected when authorized.

Definition 53 Security Testing

53. Vulnerability Scanning

Vulnerability scanning is the process of using tools and techniques to identify known weaknesses or potentially insecure configurations in systems and applications.

Vulnerability scanners can help organizations prioritize security work, but scan results require human review. A finding does not always mean that a system is actually exploitable, and organizations should verify results before taking action.

Definition 54 Security

54. Defense in Depth

Defense in depth is a security strategy that uses multiple layers of protection instead of depending on a single control. Layers can include firewalls, authentication, encryption, endpoint protection, monitoring, backups, and secure configuration.

The purpose is to make security failures less damaging. If one control fails or is bypassed, another layer may still prevent, detect, or limit the impact of the incident.

Definition 55 Security

55. Security Assessment

A security assessment is a structured evaluation of systems, networks, applications, processes, or controls to identify security weaknesses and determine whether security requirements are being met.

Security assessments can include configuration reviews, vulnerability scanning, interviews, log analysis, and authorized technical testing. The results can help an organization decide where security improvements are needed.
