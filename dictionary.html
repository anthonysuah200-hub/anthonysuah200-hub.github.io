📚 CYBERSECURITY DICTIONARY

Learn the Language of Cybersecurity

Understand important cybersecurity terms using simple, beginner-friendly explanations.

IP Address

Networking

A numerical address used to identify a device on a network.

DNS

Networking

The Domain Name System translates domain names into IP addresses.

Firewall

Security

A security system that controls network traffic according to defined rules.

Encryption

Security

The process of transforming readable information into protected data.

Authentication

Identity

The process of verifying that a person or system is who they claim to be.

MFA

Identity

Multi-factor authentication requires more than one verification method.

SQL Injection

Web Security

A vulnerability where malicious SQL input is used to manipulate a database query.

XSS

Web Security

Cross-Site Scripting allows unwanted scripts to execute in another user's browser.

HTTPS

Web Security

A secure version of HTTP that protects communication using encryption.

Malware

Security

Malicious software designed to damage, disrupt, spy on or gain unauthorized access to systems.

Ransomware

Malware

Malware that prevents access to data or systems and demands payment from victims.

Trojan

Malware

Malicious software that disguises itself as legitimate software.

Phishing

Security

A social engineering technique used to trick people into revealing information or taking unsafe actions.

Vulnerability

Security

A weakness in software, hardware, configuration or processes that could be exploited.

Exploit

Security

A technique or code that takes advantage of a vulnerability.

Zero-Day

Security

A vulnerability that is unknown or has not yet been properly addressed by its developer.

Authorization

Identity

The process of determining what an authenticated user is allowed to access or do.

VPN

Networking

A virtual private network creates an encrypted connection between a device and a network service.
